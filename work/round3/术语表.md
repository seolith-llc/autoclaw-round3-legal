# 术语表（写作规范）

本表规定 `work/round3/` 全部文档的统一写法。改稿、新增文档一律照此执行。

## 一、当事人

| 场景 | 规范写法 | 不用 |
| --- | --- | --- |
| 合同正文、备忘录的条款分析 | 甲方 / 乙方 | 客户 / 供应商（指代具体当事人时） |
| 面向不特定读者的清单、公开帖 | 客户 / 服务商 | 甲乙方（读者不知道谁是甲） |

理由：合同关系里"甲方乙方"是法律主体身份，"客户供应商"是商业角色，混用会让条款指向变模糊。

## 二、文件

| 概念 | 规范写法 | 不用 |
| --- | --- | --- |
| 乙方提供的合同文本 | 供应商原稿 | 乙方原稿、供应商稿、原稿（单独出现） |
| 带修订痕迹的文本 | 修订对照稿 | 修订模式红线、红线稿、修订稿 |
| 采纳修订后的文本 | 修订后清洁版（简称清洁版） | 定稿、终稿、干净文本 |

**“红线”只表示不可让步的合规底线**（如“红线不让”“合规红线”），不再指修订文件。
这是本轮修正的主要歧义：同一份材料里“红线”既当文件又当底线，读者会误判。

## 三、专业术语

| 概念 | 首次出现写法 | 其后 |
| --- | --- | --- |
| 服务水平协议 | 服务水平（SLA） | SLA |
| 个人信息委托处理协议 | 《个人信息委托处理协议》（DPA） | DPA |
| 法规与案例数据库 | 元典库（法规与案例检索） | 元典库 |
| 面向公众的同一事物 | 法规数据库 | — |

## 四、引证

- 法律条文统一用汉字条号：《民法典》第五百一十条，不写 §510。
- 项、款用中文序号：第四百九十七条第（三）项、第六十四条第三款。
- 每个结论最多保留 1–3个依据；引文与官方原文逐字一致，归纳内容标明为归纳。
- 数据库不可用时只写官方链接，不伪造 `[[legal:ft:]]` 类标记。

## 五、动作与状态

| 规范写法 | 不用 |
| --- | --- |
| 审查 | 审阅 |
| 修订 | 修改（指 redline 动作时） |
| 必改 / 可让步 / 红线不让 / 程序必做 | 高优先级、低优先级等模糊说法 |

## 六、标点

- 中文段落用全角标点，引号用“ ”，不用英文直引号（英文段落除外）。
- 数字与中文之间不加空格；百分比写作 0.05%。
- 文件名、代码、命令用反引号。
