# step005 - Rebuild in US English on US law

## Request

```text
I want this in strictly US english. Why do I have these chinese/korean/japanese symbols
```

## Why the CJK characters were there

Not an encoding fault. Steps 002-004 were scoped to PRC law because the only legal data
source wired into this workspace (`legal_statute` / `legal_case`, yuan­dian backend) returns
PRC statutes and cases. The contract, memo, matrix, log and entry pack were therefore written
in Chinese. That was my scoping decision, and it did not match the reader.

Two layers of CJK existed:
1. Visible content - every deliverable was Chinese prose.
2. Invisible content - python-docx's default template ships a font table naming "MS Mincho"
   and "MS Gothic", plus theme `a:font` entries for Hans/Hant/Japanese scripts. 32 CJK
   codepoints per .docx, never rendered, but still inside the file.

## Decision

Asked once whether the law should move too; answer was "Rebuild on US law". Rebuilt rather
than translated, because an English document citing a Chinese civil code serves neither
audience.

### Authorities verified (primary sources)

Cal. Bus. & Prof. Code 17602 (automatic renewal); 15 U.S.C. 8403 (ROSCA);
Cal. Civ. Code 1798.100 (CCPA business duties); 1798.150 (private right of action);
UCC 2-316, 2-302, 2-719.

### Two errors the verification caught

1. **CCPA service-provider terms are section 1798.100(d), not (e).** (e) is the reasonable
   security duty. An early draft cited (e).
2. **16 CFR Part 425 does not contain a general click-to-cancel duty.** The current eCFR text
   is the prenotification negative-option plan rule (425.1). The memo therefore cites ROSCA
   and the California statute, and the log records the negative finding so a later editor does
   not "fix" it back.

### Tooling note

The PRC legal database was unusable for this task twice over: it was down, and it does not
cover US law. All US authorities were read through `fetch_content` against leginfo, eCFR and
the Legal Information Institute. The log states this rather than implying a database search.

### CJK removal

Added `scripts/strip_cjk_fonts.py`, which rewrites the .docx package: deletes `w:font`
entries whose name contains CJK, rewrites theme script typefaces to Times New Roman, and
strips residual CJK. Wired into both builders so regeneration stays clean. Verified: 0 CJK
codepoints across all 12 files in `work/round3/`.
