## Response

复核 step002 的全部交付物，发现并修复了 7 类问题。其中最重要的一类不是措辞，而是**修订稿结构错误**。

### 1. 修订稿"只增不删"，留下自相矛盾的条文（严重）

原稿有 15 处修改写成了"保留原句 + 追加新句"，结果修订后文本同时写着"乙方不承担赔偿责任"和"乙方按 10% 支付违约金"：

| 条款 | 原做法 | 后果 |
| --- | --- | --- |
| 1.1 / 1.2 | 追加附件一与通常效用保证 | 同时保留"以官网为准""按现状提供，不作任何承诺" |
| 2.3 / 10.2 | 追加甲方解除权 | 同时保留"甲方不得解除""不得以任何理由解除" |
| 3.1 / 3.2 | 追加分期付款、锁价 | 同时保留"一次性预付全款""单方调价自动适用" |
| 4.2 | 追加 SLA 违约金 | 同时保留"仅延期，不承担赔偿责任" |
| 6.2 | 追加泄露赔偿 | 同时保留"一切损失乙方不承担责任" |
| 7.1 / 8.1 / 9.1 | 追加限制与赔偿 | 同时保留"随时下线、无需通知""单向保密 3 年""30% 封顶" |
| 12.2 | 追加法定不可抗力定义 | 同时保留"上游故障、政策调整、市场变化属不可抗力" |

改法：条款数据移入 `scripts/contract_clauses.py`，每处修改改成**成对修订**（删除原条款 + 写入新条款）。
修订标记由 24 新增 / 3 删除 变为 **24 新增 / 20 删除**。

用词表扫描验证：`不得解除`、`不承担赔偿责任`、`一次性预付`、`按"现状"提供`、`不得请求人民法院`、`全部律师费`、`以乙方官网`、`自动适用`、`不承担责任`、`无需事先通知`、`随时调整`、`仲裁费` 等 14 个冲突短语，在供应商原稿中各出现 1 次，在修订后清洁版中均为 0 次。

### 2. 条款内部不一致

- 11.1 改为法院诉讼，11.2 仍写"仲裁费"→ 改为"诉讼费"。
- 2.2 续约：原"30 日内未提异议即自动续期"与新"30 日前通知不续约"两个窗口打架 → 整段替换为通知制续约。
- 4.2 "连续超过 5 日" → "连续 5 日"。

### 3. 引证写法不统一

- 风险矩阵用 `§510` 一类符号，备忘录用汉字条号 → 矩阵全部改为《民法典》第五百一十条式写法，并补书名号。
- 备忘录"第四百九十七条第二项"与"第（三）项"混用 → 统一为"第（二）项、第（三）项"。
- 备忘录"第9.1/9.2条" → "第9.1条、第9.2条"。

### 4. 事实性错误

- 核验日志写"连续 5 次调用"失败，实际为 9 次（法规 6 次、案例 3 次）→ 已更正。
- 合同编通则解释情势变更条款写作"第三十二条第三款"，实为**第四款** → 已更正。

### 5. 标点与文字

- 中文段落混用英文直引号 `"` → 统一改为中文引号“ ”（英文帖部分保留直引号）。
- 07 清单"影响合同目的的应可解约退款"缺逗号 → 已补。

### 6. 数字口径同步

- 00 任务背景、08 参赛包（中英文）、09 看板：`24 处新增、3 处删除` → `24 处新增、20 处删除`；英文改为 `44 tracked changes: 24 insertions, 20 deletions`。
